Artículo 779.- Será obligatorio dotar a estos edificios con servicios sanitarios, unos destinados para hombres y otros para mujeres, ubicados de tal forma que no se requiera bajar o subir más de un piso para tener acceso a ellos. Adicionalmente se deberá prever que la puerta de acceso a ellos tenga un ancho mínimo libre de noventa centímetros y que cuente con un cubículo para inodoro con dimensiones mínimas de 1.50 x 2.00 metros para personas con capacidades diferentes.
Por cada 400 m² o fracción de superficie construida, se instalará cuando menos un inodoro y un mingitorio para hombres y por cada 300 m² o fracción, cuando menos un inodoro para mujeres.
Adicionalmente, se deberá prever que todas las instalaciones sanitarias cuenten con puerta de acceso, cuyo ancho mínimo libre sea de 90 centímetros, proporcionando un inodoro cuyo cubículo sea como mínimo de 1.50 x 2.00 mts.
