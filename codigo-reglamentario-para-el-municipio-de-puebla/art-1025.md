(REFORMADO, P.O. 10 DE ABRIL DE 2017)
Artículo 1025. Las construcciones provisionales, como tribunas para eventos especiales, pasos de carácter temporal para peatones o vehículos durante obras viales o de otro tipo, tapiales, obras falsas y cimbras, deben proyectarse para cumplir los requisitos de seguridad de este Título.
