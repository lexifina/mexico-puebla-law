Artículo 2083.- La capacitación que se promueva entre los Servidores públicos deberá diseñarse a partir de un modelo de capacitación propio del sector público que tome en cuenta los siguientes aspectos:
I. El perfil profesional que se requiere para el puesto;
II. El perfil de desempeño que el puesto precisa; y
III. El perfil institucional que se espera del servidor público.
