ARTÍCULO 115.- Para el caso de que los recursos de este Fondo no fueren suficientes para cubrir los adeudos a que se refiere el artículo anterior, los Municipios podrán afectar las participaciones que les correspondan, para cumplir con dichas obligaciones de pago, siempre y cuando cuenten para este caso de manera individual, con la autorización previa del H. Congreso del Estado.
